# 7boot5s
boot an iPhone 5s downgraded to iOS 7!

※How to use
1.place the iBSS.img4, iBEC.img4, devicetree.img4 and kernelcache.img4 files in 7boot5s folder
2. if you dont have gaster or irecovery download and compile it or move the one in the 7boot5s folder to /usr/local/bin
3.run sudo ./sample.sh and it will boot
